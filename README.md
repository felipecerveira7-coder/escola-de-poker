# Escola de Poker

Simulador de carreira de jogador de poker: mesas contra bots com personalidade, torneios, ranking, patrocínios, vida social, namoro, mídia e legado.

Abra `index.html` no navegador para jogar (a IA e o salvamento na nuvem só funcionam dentro do claude.ai).

Veja `CLAUDE.md` para a arquitetura e os testes.

## Desenvolvimento

O código fica em `src/` (CSS, HTML e o script dividido em partes numeradas). `npm run build` gera o `index.html` final; `npm test` gera e roda os testes num celular simulado.
